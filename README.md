# CoinVision

CoinVision is a Transfer Learning powered coin classification platform built using FastAPI and PyTorch.

## Features

- Fine-tuned ResNet18 model
- 315+ coin categories
- Grad-CAM explainability
- Top-3 predictions
- FastAPI REST API
- SQLAlchemy prediction history
- Interactive frontend

## Tech Stack

- Python
- PyTorch
- FastAPI
- SQLAlchemy
- SQLite
- HTML/CSS/JavaScript
